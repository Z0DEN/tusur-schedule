# AGENTS.md — tusur-assistent

Личный агент по учёбе в ТУСУРе: расписание, дедлайны, задания, материалы курсов,
напоминания. Источники — публичный `timetable.tusur.ru` и СДО (`sdo.tusur.ru`,
Moodle 4.5) под своей учётной записью.

Владелец задачи — пользователь `BlesK`, группа **735-1**, Факультет безопасности,
2 курс. GitHub-аккаунт — **`Z0DEN`**; push идёт через deploy key и алиас
`github-z0den` (см. `docs/stack.md` §5).

## Vikunja: правила работы

- Задачи создавать через MCP (`tasks_create`), а не правкой БД: SQLite в `./db`
  не трогать руками.
- `db/` и `files/` — личные данные, в git не попадают (`.gitignore`).
- Проект = предмет (`ЧМ`, `ТВиМС`, `Физика`, …); `Inbox` — временный приёмник.
- Напоминания держать в одном месте (сейчас — в клиенте на телефоне).
- CalDAV (`/dav/`) и MCP (`/api/v2/mcp`) — разные токены, не путать.
- В MCP Vikunja поля называются `project` (не `project_id`) при создании и
  `task` (не `id`) при чтении/правке/удалении.
- Своих полей у задачи нет: оценка — метка `est-3h` из лестницы `est-*`.

## Границы

- `timetable.tusur.ru` — только чтение. Запросы не чаще одного раз в 2–3 с,
  не больше ~10 подряд: за серию быстрых запросов сайт блокирует IP на уровне TCP.
- `sdo.tusur.ru` — только своя учётная запись, никаких чужих курсов и данных.
- `~/opencode/math-solver/materials/` — **read-only для агентов** (запрет в
  `opencode.json` того проекта). Материалы туда кладёт отдельный скрипт
  `tools/sdo_import.py`, не агент.
- Секреты: authtoken календаря СДО и любые cookies — в файлы с правами 600
  (`~/.config/tusur/`), никогда в репозиторий и никогда в чат.

## Проверки

- `python3 -c "import ast; ast.parse(open('parser.py').read())"` — синтаксис.
- `python3 main.py --fixture fixtures/735-1.html --group 735-1 --out /tmp/t.ics --state /tmp/s.json`
  — сборка без сети; ожидаем 3 события на текущей неделе.
- Повторный прогон с тем же `--state`: `SEQUENCE` не растёт (идемпотентность).
- Правка аудитории в фикстуре: `SEQUENCE` становится 1 только у изменённых пар.
- `.ics` валидировать разворотом свёрнутых строк, балансом `BEGIN/END:VEVENT`
  и пределом 75 октетов на строку.

## Публикация

- **Локальная папка:** `~/opencode/tusur-assistent` (имя папки ни на что не влияет,
  код не содержит абсолютных путей).
- **Репозиторий:** `tusur-schedule` — имя на GitHub менять нельзя без смены URL
  подписки в календаре (см. ниже). `git@github.com:Z0DEN/tusur-schedule.git` (публичный; Pages на
  приватном требуют Pro).
- Доступ: **deploy key** `~/.ssh/z0den-tusur` (ed25519, без пароля, права 600),
  алиас в `~/.ssh/config` — `Host github-z0den`. Ключ repo-scoped, поэтому в
  remote используется алиас: `git@github-z0den:Z0DEN/tusur-schedule.git`.
  В настройках deploy key включить **Allow write access**, иначе локальный push
  .ics невозможен.
- Pages: Settings → Pages → Deploy from a branch → `main` / `/`.
- Итоговые ссылки подписки: `https://z0den.github.io/tusur-schedule/<файл>.ics`.
- Старый ключ `~/.ssh/matvey-github` из блока `Host github.com` в конфиге
  отсутствует (битая ссылка) — не мешает, так как push идёт через алиас.

## Правила

- Не печатать и не коммитить токены, cookies, `sesskey`.
- Не ходить в СДО браузером «наугад»: сначала `docs/verified-facts.md`.
- Пустая неделя в расписании — норма (расписание публикуют волнами), не ошибка.
- Любое изменение формата `.ics` (UID, SUMMARY, TZID) проверять на подписке
  в реальном календаре: при смене UID события дублируются.
